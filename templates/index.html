ℹ️ Was bedeuten ICP-Score, Tier-Farbe & Eröffnung? (aufklappen)

ICP-Score (0–100 %): Anruf-Priorität. 100 % = perfekter Fit, sofort anrufen. 0 % = ignorieren. Höher ist immer besser.

Tier-Farbe: A/Grün = heiß (≥65 %) B/Gelb = mittel (40–64 %) C/Rot = niedrig (<40 %)

Spalte "Eröffnung": Bald eröffnend = eröffnet erst noch, hat garantiert kein Buchungssystem (+20 Punkte) · Neu eröffnet = aktiv, aber unter 5 Bewertungen, vermutlich frisch (+15 Punkte, Schätzung) · Etabliert = alles andere, kein Bonus.

"In DB seit": Datum, an dem dieses Tool den Laden zuerst gefunden hat — nicht das echte Google-Eröffnungsdatum (das gibt's über die API nicht).
